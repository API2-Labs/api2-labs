API2 LABS / PROJECT 01

Mock APIs without the setup.

API2 Mock is a small, stateless HTTP utility for prototypes, demos and integration tests. Echo requests, generate JSON, test status handling and inspect headers — no account required.

Try it Read the API 
curl https://api2.win/api/mock?status=200&body=%7B%22hello%22%3A%22world%22%7D

/api/mock

/api/status/:code

Return a chosen HTTP status for testing error handling.

/api/status/404
GET

/api/uuid

Generate a UUID using the runtime's cryptographic UUID generator.

/api/uuid
GET

/api/time

Return the current server-side ISO timestamp and Unix time.

/api/time

ABOUT API2 LABS

Small developer tools with simple interfaces.

API2 Labs is an independent software project building practical developer utilities, experiments and open-source tools. API2 Mock is the first project.

API2 Mock has no application database and does not intentionally persist request payloads. Do not send secrets or sensitive personal data to public test endpoints.
